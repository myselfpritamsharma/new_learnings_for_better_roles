## UNDERSTANDING THE DUAL GOAL

### **SEBI Grade A IT Exam Priorities:**
- **Breadth:** Comprehensive CS fundamentals (OS, Networks, DBMS, DSA, Security)
- **Depth:** Theory-heavy, mathematical rigor (scheduling algorithms, normalization, concurrency)
- **Question Type:** MCQs (1-mark, 2-mark) testing core concept understanding
- **Cutoff:** ~60–70% to clear (sectional + aggregate)

### **Tier-1 PBC SDE-2/3 (65–70 LPA) Interview Priorities:**
- **System Design (40%):** Distributed systems, microservices, scalability, trade-offs
- **Advanced DSA (30%):** Hard problems, optimization, real-world patterns
- **Depth in 2–3 domains:** Deep expertise in either (backend architecture) OR (data systems) OR (infrastructure)
- **Behavioral (15%):** Leadership, technical decision-making, mentorship readiness
- **Core CS (15%):** Spot-checks on OS/Networks/DBMS (not deep dives like SEBI)

### **The Alignment:**
```
COMMON GROUND (Study once, benefit both):
├─ DSA Fundamentals (Arrays, Trees, Graphs, DP) → Both need mastery
├─ DBMS Concurrency & Indexing → Both need deep understanding
├─ OS Scheduling & Memory → Both test this
├─ Networking TCP/IP → Both test this
└─ System Design Patterns (SOLID, Design Patterns) → Both leverage

SEBI-SPECIFIC (Exam-focused):
├─ DBMS Theory depth (normalization edge cases, B+ trees mechanics)
├─ OS Theory depth (banker's algorithm, exact scheduling formulas)
└─ Breadth across security/cryptography, web standards

PBC-SPECIFIC (Interview-focused):
├─ HLD System Design (5+ complex systems, capacity planning, trade-offs)
├─ Advanced DSA (solve hards in 30 mins, optimize to optimal solution)
└─ Behavioral readiness + leadership narratives for 65–70 LPA
```

## 65–70 LPA TARGETING STRATEGY

### **What Gets You to 65–70 LPA at SDE-2/3 Level?**

#### **1. System Design Mastery (60% of interview score)**
- **Requirement:** Design 3+ systems flawlessly in 45 mins each
- **What examiners evaluate:**
  - Correctness of architecture
  - Handling scale (1M–1B users)
  - Trade-off justification (CAP theorem, consistency models)
  - Deep understanding of components (caching, message queues, databases)
- **To achieve:** Implement 8–10 different HLD systems, not just 5
- **Additional prep:** ByteByteGo weekly videos, Leetcode HLD problems

#### **2. Advanced DSA Problem-Solving (20% of interview score)**
- **Requirement:** Solve hards optimally in 30–40 mins
- **What examiners evaluate:**
  - Optimal time/space complexity
  - Real-world optimization (e.g., "scale to 1B records")
  - Clean, readable code
- **To achieve:** Solve 20+ hard problems, optimize each to perfection
- **Additional prep:** Study meta-patterns (sliding window variants, DP optimizations)

#### **3. Behavioral & Communication (15% of interview score)**
- **Requirement:** Answer "leadership" questions convincingly
  - "Tell me about a time you made a technical decision"
  - "How do you handle disagreement with senior engineers?"
  - "Design a team structure for your system"
- **To achieve:** Prepare 5–7 polished STAR narratives
- **Additional prep:** Mock behavioral interviews, salary negotiation study

#### **4. Domain Expertise (5% of interview score)**
- **Requirement:** Deep knowledge in 1 specialized area
  - Options: Distributed caching, real-time systems, data pipelines, API design
- **To achieve:** Choose 1 domain, read 2–3 papers, implement 1 system
- **Additional prep:** Read AWS whitepapers or system design case studies
